# Словарь данных

Описание колонок всех таблиц проекта. `raw` — исходные файлы из `data/raw/`, `processed` — очищенные версии из `data/processed/` (в них дополнительно появляются `is_premium` и `is_new_moscow`).

## rentals — объявления об аренде (20 000 строк)

| Колонка | Тип | Описание |
|---|---|---|
| `id` | текст | Уникальный ID объявления |
| `date_posted` | дата | Дата публикации |
| `district` | текст | Район |
| `okrug` | текст | Округ (11 округов Москвы; `TAO`/`NAO`/`ZelAO` — Новая Москва) |
| `lat`, `lon` | число | Координаты объекта |
| `total_area` | число | Общая площадь, м² |
| `rooms` | число | Число комнат (1–4) |
| `floor` | число | Этаж |
| `total_floors` | число | Этажность дома |
| `building_year` | число | Год постройки дома |
| `building_type` | текст | Тип дома: `brick` — кирпичный, `monolith` — монолитный, `panel` — панельный, `modern_panel` — современная панель, `stalin` — сталинка, `khrushchev` — хрущёвка |
| `renovation` | текст | Ремонт: `cosmetic` — косметический, `euro` — евроремонт, `designer` — дизайнерский, `no_renovation` — без ремонта |
| `furnished` | bool | Есть мебель |
| `pets_allowed` | bool | Разрешены животные |
| `deposit_months` | число | Депозит, в месячных ставках аренды (0–2) |
| `metro_station` | текст | Ближайшая станция метро |
| `metro_line` | текст | Линия метро |
| `metro_distance_min` | число | Время до метро, мин |
| `to_center_km` | число | Расстояние до центра города, км |
| `monthly_rent_rub` | число | Цена аренды в месяц, руб. |
| `rent_per_sqm` | число | Цена аренды за м² в месяц, руб. — основная величина для анализа |
| `is_premium` *(processed)* | bool | Премиум-сегмент, метод IQR по `rent_per_sqm` внутри года публикации (см. «Премиум-сегмент» ниже) |
| `is_new_moscow` *(processed)* | bool | Объект в Новой Москве (`okrug` ∈ TAO/NAO/ZelAO) |

| Колонка | Тип | Описание |
|---|---|---|
| `year_month` | дата | Месяц (первое число) |

## Премиум-сегмент: как считается `is_premium`

Порог = Q3 + 1.5 × (Q3 − Q1) по цене за м², считается **отдельно для каждого года** колонки `date_posted` и отдельно в каждой из трёх таблиц. Объект помечается премиумом, если его цена за м² не ниже порога своего года.

Изначально порог считался один на весь период 2020-2026. Так делать нельзя: цены за период выросли на 55%, порог остался на месте, и доля премиума по годам поднималась с 2.0% до 8.0% — колонка частично кодировала дату публикации, а не стоимость жилья. Ошибка разобрана в п.8.5.2 и исправлена в п.8.5.3 (`notebooks/deep_analysis.ipynb`), сравнение двух методов по годам есть в каждом ноутбуке очистки.

Новая Москва из расчёта порога **не** исключается: она образует компактный кластер низких цен ниже Q1/Q3 и границу премиума не смещает.
